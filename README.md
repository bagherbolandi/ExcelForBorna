# ExcelForBorna — سامانه مدیریت و کنترل پروژه در بستر اکسل
**نسخه 2.0 — چرخه کامل «سفارش تا تصویب مدیریت ارشد» (53 شیت)**

سامانه جامع گردش کار پروژه از **دریافت و بررسی سفارش توسط فروش** تا
**تأیید / رد / برگشت برای اصلاح توسط مدیریت ارشد** — با:

- **ارتباط کامل بین مراحل** (هر مرحله خروجیِ مرحله قبل را با فرمول زنده می‌خواند)
- **کنترل دسترسی نقش‌محور** — هر واحد فقط بخش خودش را ویرایش می‌کند؛ مدیر پروژه
  همه بخش‌ها را **می‌بیند** ولی فقط در بخش خودش کار می‌کند
- **لیست‌های مرجع اقلام و تجهیزات** — مهندسی از مرجع انتخاب می‌کند؛ بازرگانی
  همان ردیف‌ها را قیمت می‌دهد
- **نرخ ارز برای اقلام/تجهیزات وارداتی** (از `Settings` — تغییر نرخ، قیمت‌های
  ریالی را زنده به‌روز می‌کند)
- **تقدم و تأخر ورود اطلاعات (گیتینگ)** — اگر اطلاعات مؤثر مرحله قبل ثبت نشده
  باشد، اکسل ورود داده در مرحله بعد را **رد می‌کند** (نه فقط هشدار)
- **داشبورد مدیریتی** — KPI + قیف + ماتریس گردش کار (✅/🔵/🔒) + نمودارها
- **گانت** — نمودار میله‌ای برنامه/عملکرد فعالیت‌ها با رنگ وضعیت

## تحویلی‌ها (Deliverables)

### A. فایل Excel نهایی
**`output/ExcelForBorna.xlsx`** — ۵۳ شیت راست‌به‌چپ، Excel Table، Data Validation
(شامل گیت‌های مسدودکننده)، فرمت‌دهی شرطی، نمودار، محافظت شیت و
محدوده‌های ویرایش رمزدار برای هر نقش.

## اصل صداقت (anti-fabrication)
هیچ عدد/نرخ سازمانی داخل فرمول Hard-code نیست؛ همه نرخ‌ها در `Settings` با
برچسب `ASSUMPTION` هستند و عناصر فاقد اطلاعات سازمانی صراحتاً اعلام شده‌اند.
