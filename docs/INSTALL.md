این فایل سه سطح دارد؛ هر کدام اختیاری است ولی سطح ۲ و ۳ تجربه «نرم‌افزاری» (ورود و دسترسی نقش‌محور) را می‌سازد.

| سطح | قابلیت | نیاز |
|---|---|---|
| ۱ | فایل اکسل کامل با فرمول‌ها، تقویم شمسی، گانت، داشبورد — بدون هیچ نصبی | فقط Excel 2016+ دسکتاپ |
| ۲ | ورود کاربری، مخفی‌شدن برگه‌های غیرمجاز، اعمال ماتریس دسترسی | نصب ماکروی `vba/modBorna.bas` + ذخیره XLAM/XLSM |
| ۳ | دسترسی واقعی روی شبکه (هر واحد فقط فایل خود را ببیند/بنویسد) | استقرار در Share با NTFS — `docs/IT-DEPLOYMENT.md` |

> واحد فایل: **Excel دسکتاپ ویندوز**. مرورگر/پیش‌نمایش موبایل، فرمت‌های فارسی و تقویم شمسی را درست نشان نمی‌دهند.

## ۱) استفاده بدون ماکرو (سطح ۱)

1. فایل `out/Project_Management_Borna.xlsx` را کپی کرده و برای هر پروژه نام‌گذاری کنید:
   `Project_BC-P-1405-01.xlsx`
2. برگه **راهنما** را بخوانید؛ برگه **شناسنامه** را کامل کنید؛ داده‌های نمونه (مخزن FRP) را با داده واقعی جایگزین کنید.
3. رنگ زرد = ورودی، طوسی = فرمول (دست نزنید). تاریخ‌ها شمسی با قالب `1405/07/12` (رقم فارسی یا لاتین فرقی نمی‌کند؛ جداکننده `/` یا `-`).
4. رمز پیش‌فرض قفل شیت‌ها: `Borna@1405` و رمز قفل ساختار: `Borna-Admin-1405` — **حتماً عوضشان کنید**:
   - Review → Unprotect Sheet (با رمز) → تغییر → دوباره Protect؛
   - Review → Protect Workbook برای ساختار.
   - برای بازسازی خودکار فایل (همه قفل‌ها هماهنگ)، بهتر است فایل را از اسکریپت بسازید: `python build/build_workbook.py --pwd-user "Jadid-Pwd1!" --pwd-structure "Admin-Pwd1!"` (بخش ۳).

## ۲) نصب ماکروی ورود/دسترسی (سطح ۲)

1. فایل xlsx را باز کنید → کلید `Alt+F11` (ویرایشگر VBA).
2. منوی `File → Import File…` → فایل **`vba/modBorna.bas`** را انتخاب کنید.
3. در پنجره Project، روی **ThisWorkbook** دابل‌کلیک و کد **`vba/ThisWorkbook.txt`** را در آن جایگذاری کنید.
4. **ذخیره با نوع Excel Macro-Enabled Workbook (`.xlsm`)** و بستن/بازکردن مجدد فایل.
5. تنظیم رمز VBA Project (تا مقادیر ثابت ماژول ساده خوانده نشود): در VBE راست‌کلیک روی پروژه → `VBAProject Properties → Protection → Lock project for viewing` (رمز را در دسترس IT نگه دارید).
6. **تغییر رمزها در دو نقطه**: ثابت‌های بالای `modBorna.bas` (PWD_SHEETS / PWD_STRUCTURE) باید با قفل‌های فایل یکی باشد؛ اگر فایل را بازسازی کرده‌اید (مرحله ۴) لازم نیست دستی تغییر دهید.

### نحوه ورود هر کاربر
- فایل را باز کنید → در برگه «ورود» نام کاربری و رمز (جدول کاربران برگه تنظیمات) → `Alt+F8 → Borna_Login → Run`.
- پس از ورود، فقط برگه‌های مجاز همان نقش باز می‌شوند (مطابق ماتریس دسترسی در «تنظیمات»).
- خروج: `Alt+F8 → Borna_Logout`. ورود اضطراری IT: `Borna_Admin`.
- اگر ماکرو مسدود است: فایل را در **Trusted Location** شبکه قرار دهید (بهترین روش) یا File → Options → Trust Center → Trust Center Settings → Macro Settings → «Disable with notification» و فعال‌سازی نوار اخطار. برای کل سازمان با GPO: `User Configuration → Policies → Administrative Templates → Microsoft Excel → VBA Trust Center → Trusted Locations`.

### گردش پیشنهادی (نقش‌ها)
| نقش | می‌نویسد | می‌بیند |
|---|---|---|
| واحد ثبت سفارش | شناسنامه | راهنما، ورود، گانت، داشبورد |
| مدیر پروژه | امکان‌سنجی، گانت، جمع‌بندی، هزینه‌واقعی، ریسک، تغییرات | **همه** (بدون ویرایش بقیه) |
| مهندسی | BOM/نفرساعت، مدارک | گانت، داشبورد، بازرگانی (نمایش) |
| بازرگانی داخلی/خارجی | بازرگانی (قیمت BOM) | BOM (نمایش)، داشبورد، گانت |
| برنامه‌ریزی و انبار | برنامه‌ریزی | BOM، بازرگانی، داشبورد |
| مالی | مالی، هزینه‌واقعی | فروش (نمایش)، داشبورد |
| فروش | فروش | مالی (نمایش)، شناسنامه |
| مدیریت ارشد | تصویب (حکم نهایی) | همه |
| مدیر سیستم | تنظیمات | — (با Borna_Admin) |

ماتریس را می‌توانید فقط از همان جدول «ماتریس دسترسی» در تنظیمات تغییر دهید (W/R/-)؛ ماکرو هر ورود آن را اعمال می‌کند.

## ۳) توسعه‌دهنده: بازسازی فایل

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python build/build_workbook.py --out out/Project_Management_Borna.xlsx        # ساخت دوباره
python build/build_workbook.py --year 1406                                    # گانت برای سال شمسی دیگر
python build/check_workbook.py out/Project_Management_Borna.xlsx              # اعتبارسنجی ساختاری
```

- تغییر سال بازه گانت: فقط `--year 1406` — سربرگ‌های شمسی، محاسبه جمعه‌ها و نوارها بازتولید می‌شوند.
- رمزهای قفل از ثابت‌های `PWD_USER` و `PWD_STRUCTURE` در ابتدای اسکریپت خوانده می‌شوند؛ پس از تغییر، فایل را بازسازی کنید و همان رمز را در `modBorna.bas` بگذارید.
